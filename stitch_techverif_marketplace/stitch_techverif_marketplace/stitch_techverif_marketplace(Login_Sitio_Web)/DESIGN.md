## Brand & Style

The design system establishes an authoritative, forensic-grade dark mode interface designed for verified computer hardware and certified mobile exchanges. The aesthetic synthesizes **Cyber-Security Diagnostics** with **Hardware Laboratory Cleanliness**, evoking the sensory feedback of an advanced testing facility and cryptographic verification terminal. 

The visual tone is clinical, calibrated, and high-assurance. Targeting PC builders, security engineers, systems architects, and technical enthusiasts, the experience replaces uncertainty with explicit telemetry, component stress-test diagnostics, and immutable proof-of-authenticity badges. Interfaces avoid decorative skeuomorphism in favor of structural clarity: razor-sharp geometry, dark slate canvases, deep navy structural panels, luminous cobalt interaction channels, and radiant neon emerald/cyan validation seals that announce verified integrity instantly.

## Colors

The palette operates on calibrated low-reflectance surfaces contrasted against luminescent verification emitters:

- **Canvas Base (`#0a0f1d`) & Card Surfaces (`#111827`, `#1e293b`):** The foundational structure. Charcoal-infused obsidian absorbs optical strain, creating a canvas where critical status states emerge with clarity.
- **Primary Cobalt (`#3b82f6`, supported by `#60a5fa`):** Signals active paths, primary execution controls, active data tabs, and checkout pathways.
- **Secondary Emerald (`#10b981`, supported by `#34d399`):** Reserved exclusively for verified diagnostics: TechShield escrow protection, 100% component pass grades, hardware burn-in certificates, and cryptographic verification seals.
- **Tertiary Cyan (`#06b6d4`):** Denotes real-time telemetry, serial lookup validation, benchmark index percentiles, and live sensor monitors.
- **Borders & Seams (`#1e293b`, `#334155`):** Razor-thin structural lines providing spatial bounding boxes for dense technical readouts.
- **Text Tiers (`#f8fafc`, `#94a3b8`, `#64748b`):** Delivers clean contrast without eye fatigue during extended forensic reviews.

## Typography

Typography prioritizes functional density and exact reading comprehension:

- **Structural Prose & Layouts (`Inter`):** Renders titles, marketing specs, contextual listing descriptions, and transactional guides. Tight letter-spacing on headline levels anchors a confident, engineering-forward stance.
- **Hardware Telemetry & Cryptographic Hashes (`JetBrains Mono`):** Dedicated to technical data streams, IMEI numbers, silicon batch IDs, thermal margins, clock frequencies, and blockchain/escrow certificate tokens. Mono-spaced figures ensure tabular alignment across comparison matrices and burn-in logs.

## Layout & Spacing

The layout is anchored by a structured 12-column fluid grid system on desktop (`min-width: 1024px`) with a constrained maximum container width of `1440px`. Mobile viewports (`< 768px`) collapse into a rigid 4-column column structure with tight `1rem` margins to maximize visible data surface area.

Spacing utilizes an unambiguous 4px baseline rhythm. Hardware audit lists, diagnostic readouts, and benchmark tables leverage dense horizontal packing (`space-xs` and `space-sm`) to ensure complete technical specs remain above the viewport fold without visual distraction.

## Elevation & Depth

Visual depth is achieved through layered dark tone stratification combined with 1px hairline borders and luminous photonic halos rather than traditional drop shadows:

- **Level 0 (Canvas):** Pure dark background `#0a0f1d` with no elevation.
- **Level 1 (Panels & Feed Cards):** `#111827` backed by a crisp hairline border `1px solid #1e293b`.
- **Level 2 (Active Modules & Hardware Inspectors):** `#1e293b` with border `1px solid #334155` and a tight edge shadow `0 4px 20px -2px rgba(0, 0, 0, 0.5)`.
- **Level 3 (Diagnostic Overlays & Verification Flyouts):** Layered `#0f172a` with frosted backdrop-filter (`blur(16px)`) and `1px solid #3b82f640`.
- **Luminescent Halo (Verified Hardware Only):** High-tier certified items receive a hardware-level accent rim: `box-shadow: 0 0 0 1px #10b981, 0 0 24px -4px rgba(16, 185, 129, 0.18)`.

## Shapes

The design system implements an exact, low-radius shape profile (`roundedness: 1`):

- **Inputs, Buttons, Badges, and Micro-Toggles:** `0.25rem` (4px). Clean, decisive, and reminiscent of hardware chassis fabrication.
- **Cards, Diagnostic Modules, and Viewport Windows:** `0.5rem` (8px). Structural stability without looking soft.
- **Verification Pills & Status Nodes:** Full roundedness (`9999px`) reserved purely for high-visibility dynamic indicators (e.g., `ONLINE`, `AUTHENTICATED`, `BENCHMARK PASSED`).

## Components

### Action Buttons
- **Primary Execution:** Solid cobalt (`#3b82f6`) with `#0a0f1d` or `#ffffff` high-contrast text, 4px corner radius, and subtle glow on hover (`box-shadow: 0 0 16px rgba(59, 130, 246, 0.4)`).
- **Verified Escrow Purchase:** Emerald background (`#10b981`), high-contrast dark slate text (`#0a0f1d`), pairing an integrated lock/shield glyph to indicate cryptographic fund security.
- **Secondary / Ghost Action:** Transparent background bounded by `1px solid #334155` with `#f8fafc` text. Hover shifts border to `#60a5fa` with a subtle `#3b82f610` surface wash.

### Verification Chips & Diagnostic Badges
- Encased in a 4px corner frame, styled in `JetBrains Mono` at `label-mono-sm` scale.
- **Hardware Pass Badge:** `#064e3b` background at 40% opacity, framed in `1px solid #10b981`, emerald text `#34d399` displaying pass score (e.g., `PASS: 99.4% SILICON HEALTH`).
- **Telemetry Indicators:** Cyan-tinted badge (`#083344` base, `1px solid #06b6d4`, text `#67e8f9`) for live frequencies and thermal ceilings.

### Component Listing Cards
- Built over `#111827` with a razor `1px solid #1e293b` frame.
- High-contrast typography displays model and benchmark tier prominently.
- Lower telemetry strip details hardware testing status with tabular mono font figures for battery cycle counts, VRAM integrity checks, or factory warranty status.
- Hover triggers border accentuation to `#334155` with an ambient glow along the perimeter.

### Checkboxes, Radio Buttons & Diagnostic Sliders
- Checkboxes: 4px rounded rectangles formed by `1.5px solid #334155` against `#0a0f1d`. Active checked state fills with `#10b981` delivering a crisp obsidian check icon.
- Toggles: Segmented dark pill rail (`#0f172a` with `1px solid #1e293b`) containing a glowing cobalt or emerald thumb.

### Input Fields & Terminal Search
- Background: Deep charcoal slate (`#0a0f1d`) bordered by `1px solid #1e293b` with `#f8fafc` input text and `#64748b` placeholder copy.
- Active focus state deploys a sharp `1px solid #3b82f6` border with a restrained `0 0 12px rgba(59, 130, 246, 0.25)` ambient back-glow.
- Integrated keyboard shortcuts (e.g., `[CMD + K]`) rendered in `JetBrains Mono` as framed mini-keys on the right trailing edge.

### Hardware Diagnostic Matrix
- Tabular grid with alternate row tinting (`#111827` and `#0f172a`), bound by hairlines (`#1e293b`).
- Columns align test parameters (e.g., `3DMark TimeSpy`, `Prime95 Thermal Peak`, `IMEI Clean Status`) alongside real-time verification hashes and timestamp records.
