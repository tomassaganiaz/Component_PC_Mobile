# ERS - Electronic Resale System

## Plataforma de Compra y Venta de Componentes Electrónicos

---

## Objetivo Principal

### Compra y venta segura de componentes usados

ERS nace para resolver la principal problemática del mercado de electrónica usada: **la falta de confianza**. Los compradores no saben si el producto realmente cumple con lo que el vendedor dice, no hay garantías y el riesgo de estafa es alto.

**Nuestra solución:** Un proceso de verificación profesional que certifica cada producto usado antes de llegar al comprador.

---

## ¿Cómo Funciona la Verificación?

### Flujo Completo del Producto Usado

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  PASO 1: Vendedor publica producto                                          │
│  ─────────────────────────────────                                          │
│  • Sube fotos y descripción                                                 │
│  • Declara: tiempo de uso, tipo de uso, estado general                      │
│  • Solicita certificado de autenticación (opcional)                         │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  PASO 2: Retiro del producto                                                │
│  ────────────────────────────                                               │
│  • Empleado ERS se dirige al domicilio del vendedor                         │
│  • Retiro CON permiso y coordinación previa del vendedor                    │
│  • Registro fotográfico del estado al momento del retiro                    │
│  • Firma de documento de custodia temporal                                  │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  PASO 3: Testing y Verificación Profesional                                 │
│  ────────────────────────────────────────                                   │
│                                                                             │
│  3.1 - Verificación de declaración del vendedor                            │
│        ✓ Tiempo de uso declarado vs real (lectura interna)                  │
│        ✓ Tipo de uso declarado (gaming, oficina, minería, etc.)            │
│        ✓ Calidad de vida del producto según lo declarado                    │
│                                                                             │
│  3.2 - Tests de calidad general                                             │
│        ✓ Estado físico/cosético (rayones, golpes, desgaste)                │
│        ✓ Funcionalidad básica (encendido, puertos, conectividad)           │
│        ✓ Temperatura y rendimiento bajo carga                              │
│        ✓ Ruido, vibraciones, olores anormales                              │
│                                                                             │
│  3.3 - Tests en uso (según tipo de producto)                               │
│        ✓ GPU: benchmarks, temperaturas, artefactos, minado previo          │
│        ✓ CPU: stress test, estabilidad, overclocking previo                │
│        ✓ RAM: memtest, errores, frecuencia real                            │
│        ✓ Almacenamiento: salud de sectores, velocidad lectura/escritura    │
│        ✓ Móviles: batería, pantalla, sensores, cámara, desgaste           │
│                                                                             │
│  3.4 - Revisión interna de horas de uso                                    │
│        ✓ Lectura de contadores internos del hardware                       │
│        ✓ Comparación con lo declarado por el vendedor                      │
│        ✓ Análisis de patrones de uso (intensivo vs moderado)               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  PASO 4: Calificación y Certificación                                       │
│  ────────────────────────────────────                                       │
│                                                                             │
│  El producto recibe una calificación basada en:                             │
│                                                                             │
│  ┌─────────────────┬────────────────────────────────────────┐              │
│  │ Criterio        │ Ponderación                           │              │
│  ├─────────────────┼────────────────────────────────────────┤              │
│  │ Estado físico   │ 25%                                   │              │
│  │ Funcionalidad   │ 30%                                   │              │
│  │ Horas de uso    │ 20%                                   │              │
│  │ Calidad de vida │ 15%                                   │              │
│  │ Veracidad       │ 10% (coincide con lo declarado)       │              │
│  └─────────────────┴────────────────────────────────────────┘              │
│                                                                             │
│  Calificación final:                                                        │
│  ★★★★★ Excelente - Como nuevo, pocas horas, perfecto estado               │
│  ★★★★☆ Muy Bueno - Leve desgaste, totalmente funcional                    │
│  ★★★☆☆ Bueno - Desgaste visible, funcional con limitaciones menores       │
│  ★★☆☆☆ Regular - Desgaste notable, funcional con consideraciones          │
│  ★☆☆☆☆ Malo - No recomendado para reventa                                 │
│                                                                             │
│  Si el producto APRUEBA → Se publica con etiqueta "✓ VERIFICADO"          │
│  Si el producto NO APRUEBE → Se notifica al vendedor, no se publica       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  PASO 5: Publicación con Certificado                                        │
│  ────────────────────────────────────                                       │
│                                                                             │
│  El comprador ve en la publicación:                                         │
│  • Fotos reales del producto (tomadas por el verificador)                  │
│  • Informe completo de verificación                                         │
│  • Calificación con estrellas                                               │
│  • Detalle de horas de uso reales                                           │
```

## Garantía Post-Venta: Sistema de Custodia

### ¿Qué pasa después de la compra?

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     SISTEMA DE CUSTODIA DE PAGO                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Comprador paga → Plataforma retiene por 3 días → Vendedor recibe          │
│                                                                             │
│  ┌──────────┐      ┌──────────────┐      ┌──────────┐                     │
│  │COMPRADOR │ ───► │  ERS RETIENE │ ───► │ VENDEDOR │                     │
│  │  PAGA    │      │  3 DÍAS      │      │ RECIBE   │                     │
│  └──────────┘      └──────────────┘      └──────────┘                     │
│                                                                             │
│  Durante los 3 días el comprador puede:                                    │
│  • Verificar que el producto coincide con el informe                       │
│  • Realizar tests propios                                                   │
│  • Reportar cualquier problema o discrepancia                              │
│                                                                             │
│  Si hay problema:                                                           │
│  • El dinero NO se libera al vendedor                                      │
│  • Se inicia proceso de mediación                                           │
│  • ERS se hace cargo del producto si hay daño                              │
│  • Devolución garantizada al comprador                                      │
│                                                                             │
│  Si todo está OK:                                                           │
│  • Después de 3 días el dinero se libera al vendedor                       │
│  • Transacción completada                                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Responsabilidad de ERS

| Situación | Responsabilidad ERS |
|-----------|---------------------|
| Producto no coincide con informe | Devolución + reembolso total |
| Producto dañado en verificación | ERS paga al vendedor + reembolso |
| Producto falla en 3 días (no declarado) | Devolución + reembolso |
| Disputa comprador-vendedor | Mediación obligatoria |
| Estafa comprobada | Baneo vendedor + reembolso |

## Sistema de Quejas y Calificaciones

### Reseña de Compradores

Solo los compradores que hayan completado una compra pueden dejar reseñas. Esto garantiza que todas las opiniones sean de personas que realmente interactuaron con el vendedor y el producto.

### Cálculo de la Etiqueta

```
Fórmula de puntuación del vendedor:

  Puntuación = (Promedio calificaciones × 0.6) + (Factor quejas × 0.4)

  Donde:
  • Promedio calificaciones = media de todas las estrellas recibidas
  • Factor quejas = 5 - (porcentaje de quejas × 5)

  Ejemplo:
  • Vendedor con 4.2★ promedio y 8% de quejas
  • Puntuación = (4.2 × 0.6) + (4.6 × 0.4) = 2.52 + 1.84 = 4.36
  • Resultado: ✓ SEGURO

  Ejemplo 2:
  • Vendedor con 3.1★ promedio y 30% de quejas
  • Puntuación = (3.1 × 0.6) + (3.5 × 0.4) = 1.86 + 1.40 = 3.26
  • Resultado: ✗ NO SEGURO
```

### Flujo de una Queja

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│COMPRADOR │──►│  QUEJA   │──►│  REVISIÓN │──►│ RESOLUCIÓN│
│RECIBE    │    │REGISTRADA│    │   ERS     │    │  FINAL   │
│PRODUCTO  │    │          │    │           │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                     │               │               │
                     ▼               ▼               ▼
              Se notifica      ERS contacta    • Queja válida:
              al vendedor      ambas partes      afecta etiqueta
                                                 • Queja inválida:
                                                   se descarta
```

### Tipos de Quejas

| Tipo | Descripción | Impacto en Etiqueta |
|------|-------------|---------------------|
| Producto no coincide | Lo recibido es diferente a lo publicado | Alto |
| Producto dañado | Llegó con daños no declarados | Alto |
| Producto no funciona | No cumple su función básica | Crítico |
| Estafa | Vendedor no entregó o es falso | Crítico (baneo) |
| Comunicación | Vendedor no responde o es hostil | Bajo |
| Envío lento | Tardó más de lo acordado | Bajo |

### Protección para Vendedores

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    PROTECCIÓN CONTRA QUEJAS FALSAS                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  • Solo compradores verificados pueden quejarse                            │
│  • ERS revisa cada queja antes de afectar la etiqueta                      │
│  • Vendedor puede responder y presentar evidencia                          │
│  • Quejas falsas penalizan al comprador (baneo)                            │
│  • Historial de quejas se mantiene privado (solo promedio es público)      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Objetivo Secundario

### Venta de Productos Nuevos

Además de productos verificados, ERS permite la venta de productos nuevos de fábrica:

| Característica | Producto Nuevo | Producto Usado Verificado |
|----------------|----------------|---------------------------|
| Origen | Distribuidor oficial | Vendedor particular |
| Verificación | No necesaria | Proceso completo ERS |
| Garantía | Del manufacturer | De ERS (3 días custodia) |
| Precio | Premium (fábrica) | Accesible (mercado) |
| Certificado | Factura original | Certificado ERS |
| Retiro | Envío directo | Empleado retira y entrega |

## Resumen Ejecutivo

ERS es una plataforma que resuelve la desconfianza en la compra de componentes electrónicos usados mediante un **proceso de verificación profesional** donde un empleado certificado retira, testea y califica cada producto antes de publicarlo.

**Diferenciador clave:** Certificado de autenticidad + custodia de pago por 3 días

**Sistema de confianza:** Etiquetas de vendedor (Seguro / Intermedio / No seguro) basadas en reseñas reales de compradores

**Garantía:** ERS se hace cargo de cualquier problema post-venta

**Stack:** NestJS + React Native + PostgreSQL

**Modelo:** Marketplace con comisión + fee de verificación

**Objetivo principal:** Compra-venta segura de componentes usados

**Objetivo secundario:** Venta de productos nuevos

**Próximos pasos:** Conectar DB, implementar sistema de custodia, lanzar beta
